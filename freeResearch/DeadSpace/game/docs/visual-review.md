**地板烘焙補光（舊機制，11-03 已由下方「補光圖」取代）**：在主題設 `fill`（0 = 關）。站體建構時，依每盞房間燈的位置和照射距離，替地板頂點算一層暗光（線性色、平方衰減、各通道封頂），寫進 `xcFill` attribute，shader 再把 albedo × xcFill 加到自發光。效果：low 畫質的燈光池只有 4 盞，遠處房間不再全黑；因為加在自發光，戰爭迷霧照樣會壓暗。只有帶這個 attribute 的地板用 `Mat.floor(…, fill=true)` 這個材質變體，其他地板和模型展示頁不受影響。目前開啟的站：裁決者號 0.45、天守砲台 0.5、七號廢站 0.5。

**室外人造牆**：在主題設 `built: { rooms, wall, cap, trim }`。離這些房間類型 2 格內的牆，畫成筆直的混凝土牆；其餘的室外牆走 `rockWalls.ts` 的自然岩壁。
