# 視覺審查（美術聖經 §15）

> 每個里程碑結束前用 Playwright（headless Chromium＋SwiftShader）在固定點位截圖，逐項對照美術聖經自評。
> 截圖腳本：`tests/visual/review.mjs`（地點與介面）、`tests/visual/models.mjs`（模型陳列）、`tests/visual/fxgallery.mjs`（特效）、`tests/visual/stations.mjs`（各站）。
> 截圖本身不進版控（雲端 session 的 scratchpad），這裡記錄結論與待改項目。

## 2026-10-30 模型（異形 20、變種人 26、仿生人 3、管家）

| 項目 | 結論 |
|---|---|
| 剪影可讀性 | 38 m 外 9 種 T3 一眼可分（背部熔爐、電弧尖刺、殘影、S 形長蛇、外露核心、八足、光環泡泡、傾斜時鐘骨環、不定形團塊）。T1／T2 異形偏暗，遠看主要靠青色發光脈絡辨認，可接受。 |
| 材質三要素 | 皮膚用 `Mat.organic`（細胞紋＋clearcoat），甲殼、骨頭、機殼各自分材質，有粗糙度變化；沒有平色灰盒子。 |
| 動畫 | 待機呼吸、移動步態、攻擊前撲、0.9 秒死亡動作（依體型：側倒、後倒、撲地、縮腳、跪倒、塌陷）。 |
| 面數 | 一般單位多數 < 4000 三角形；T3 與巢類大型單位 4500–7600，都 < 10000。 |
| 發現並修正 | 邊光 shader 視線方向相反（正面整片發光、沒有邊緣效果），以及迷霧注入覆寫了 shader 快取鍵（不同注入的材質共用同一支 shader，橡膠零件被染成玩家色）。兩者都修了，人類與防護服的外觀也一起受惠。 |
| 待改 | 疫蟲（`mut.blightcrawler`）是半透明綠色膠囊，層次比其他型態少；draw call 每個模型 20–70 個 mesh，大量同屏時可考慮合併靜態部件（需要先讓 `units.ts` 移除單位時 dispose 幾何）。 |
