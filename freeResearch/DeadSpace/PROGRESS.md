## 介面（2026-11-02）

- **介面大小**：`src/ui/uiScale.ts` 依視窗自動縮放（1280×760 = 1.0、1600×900 ≈ 1.18、1920×1080 ≈ 1.42），透過 CSS `zoom` 套在 `#app` 與 `.layer` 的直接子元素；設定頁「介面大小」再乘倍率。注意：被 zoom 的元素上 `vh` 也會被放大，要用 `calc(…vh / var(--ui-zoom))`。
- **tooltip**：`src/ui/tooltip.tsx` 全域單一圖層；元素用 `tipProps()`，場景物件用 `showCursorTip()`（`src/ui/hud/WorldHover.tsx`）。
- **邊緣捲動**：`src/client/input.ts` 追蹤整個視窗的滑鼠；滑出視窗時視為停在邊緣，視窗失焦才停。設定頁可關閉、調速度（`src/client/controlPrefs.ts`）。
- **指引**：`src/ui/hud/Guide.tsx`（目標面板、一次性情境提示、G 說明面板）；提示紀錄 `xc.hints.seen`，設定頁可關閉或重設。
- **公告**：`src/ui/hud/Announce.tsx`（全場事件放大、私人訊息在 HUD 上方、自己的詠唱進度條）。
- **離開控制台**：新指令 `unpilot`（B 鍵或指令卡上方按鈕），站點、船艇、防禦無人機都適用；交回後在離開控制台／控制圈前不會被自動接回。
- **冷卻與等待**：`src/ui/hud/CdFace.tsx`（灰階、扇形、本地平滑倒數、就緒閃光）；等待進度條在 `Announce.tsx` 的 `CastBar`（詠唱、進化、船艇發射；發射倒數來自私有狀態 `launchIn`）。
- **按鍵**：Esc＝取消瞄準／遊戲選單（繼續、進化、說明、圖鑑、設定、離開對局）；V＝進化選單；G＝說明；B＝離開控制台；脫防護服要連按兩次。
- **身分數量規則**：`src/shared/roleRules.ts`（sim 開局分配與大廳／練習預覽共用，有一致性測試）。
- **太空站點**：外型在 `src/render/space/hulls.ts`（每座站獨立輪廓、依 `STATION_BY_ID` 真實半徑縮放）；client 沒有站點的 UnitDef，`units.ts` 以外觀 id（`station.<id>`）選模型。

## 已知問題

- 測試環境：2026-11-02 起這個雲端容器在**同一個瀏覽器開多個分頁**時，分頁共用 SwiftShader GPU 行程，第二個分頁卡在初始化（主選單都出不來），所以 `lobby.spec.ts`、`tools.spec.ts` 等多分頁 e2e 在這裡會逾時；舊版本（`5c77478`）一樣失敗，確認是環境問題。對應的邏輯有單元測試涵蓋；單分頁 e2e（ux、guide、audio）與兩個獨立瀏覽器的線上驗證都通過。在有 GPU 的機器上應照常可跑。
- 死因：神經毒素是在 `death.ts` 依技能 id 對應（`stations.ts` 沒標）；天守反物質打擊若施放的站已被毀才命中，仍會說「環境傷害」（罕見）；「看不見的攻擊者」依死者畫面上實際有的東西（上一個 tick 的視野）判斷，這是刻意的（見 death.ts 註解）。
- 太空：七號廢站刻意保留為最暗的站；主選單的行星夜面現在也隱約看得到陸塊（`makePlanet` 的 `nightK` 預設 0.14，想要全黑改 0）。
- 介面：說明面板英文版在 1600×900 需要捲動；小地圖圖例的顏色是從 `Hud.tsx` 的 Minimap 抄的，改色時要同步 `src/ui/strings/guide.ts`／`Guide.tsx`。
- 音訊：沒有屍體的機械單位死亡是用「低血量時在近處消失」推斷的，偶爾會在低血量機械離開視野時誤播死亡聲；只影響音效，不影響資訊。
- 音訊：雲端容器只能量測音量、沒辦法實際聽，聽感需要真人試玩確認。
- 通訊病毒事件互換名字與顏色後，畫面上看不出誰是誰，但封包裡的玩家槽位沒有重新編號，改過 client 的人仍能對回原本的人。要完全做到需要每位觀看者各自的槽位映射，暫不處理。
- 手榴彈等投射物會穿過關著的門（投射物只把牆當障礙）。
- 千面（假面者）化身後，聊天已改顯示偽裝對象的名字與顏色；但時滯殭屍被喚回後會立刻換成目前的 spawn 型，不會保留殭屍本體。
- 擬人株污染販賣機、GIT 解析器等機制依賴販賣機庫存；開局已初始化，但對局中新生成的販賣機要記得呼叫 `initVendor`。
- `src/devtools/modelGallery.ts` 是開發用模型展示頁，不進正式 build。
- 偽裝（千面）時換新 id 能擋住「用 id 連續性分辨真假」，但改過的 client 仍可記住「真本人的 id 最後出現在哪裡」來推斷；要完全防止需要每位觀看者各自的 id 別名表，暫不處理。
- 給別人唯一道具（例如基因檢測器）時，對方已有或背包滿會有不同結果，可以用來探測背包（原作行為，低風險）。
- 隱形單位仍會讓自動門打開並留下門禁紀錄（物理上合理，但等於暴露有隱形單位經過）。
- 死者附身的蛞蝓仔用旁觀者視野判斷可指揮目標，理論上能用蛞蝓的動作向活人傳遞資訊（原作也一樣）。
- 豪勇號降落時，停在它上面的船仍可發射；翠原星的轟炸系統未實作（原作的「轟炸進度」）。
- CEO 是仿生人時，仿生人重生不會補生成管家。
