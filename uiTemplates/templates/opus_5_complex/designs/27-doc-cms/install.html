環境變數 Environment — 寫入 /etc/inkbase/.env

變數必要預設值說明
INKBASE_SECRET_KEY必填—32 位元組隨機字串，用於工作階段與 Webhook 簽章；更換會使所有工作階段失效
DATABASE_URL必填—PostgreSQL 16 連線字串，需已建立 pgvector 擴充
OBJECT_STORE_URL必填—S3 相容端點，用於附件與匯出檔
PUBLIC_BASE_URL必填—對外網址，影響郵件連結與 Webhook 回呼驗證
SNAPSHOT_DEBOUNCE_MS選填2000停止輸入多久後建立快照；調低會顯著增加快照數量
BRANCH_STALE_DAYS選填30分支多久未更新即標記為停滯
AUDIT_RETENTION_DAYS選填400稽核事件保存天數，變更會寫入稽核日誌
RATE_LIMIT_RPM選填600每權杖每分鐘請求上限
SEARCH_NODE_URL選填內嵌獨立搜尋叢集位址；未設定時使用內嵌索引
SMTP_URL選填—未設定時通知僅顯示於站內信箱
OIDC_ISSUER選填—啟用單一登入；設定後本機密碼登入自動停用
LOG_LEVEL選填infodebug / info / warn / error

常見問題 Troubleshooting — 依實際回報頻率排序

遷移卡在 0014_blocks_hash 這支遷移會替既有區塊回填內容雜湊。50 萬區塊約需 6–9 分鐘，期間不要中斷。若已中斷，直接重跑即可——遷移具冪等性，會從最後一批續做。
健康檢查回 503 · search degraded 內嵌索引正在重建。以 inkbase index status 觀察進度；超過 40 萬區塊仍使用內嵌索引時，重建可能長達 40 分鐘，建議改設 SEARCH_NODE_URL。
編輯器連線每 60 秒斷一次 反向代理未放行 WebSocket 升級。Nginx 需設定 proxy_set_header Upgrade $http_upgrade 與 Connection "upgrade"，並將 proxy_read_timeout 提高到 3600。
附件上傳 403 物件儲存的 CORS 未允許 PUT 與 PUBLIC_BASE_URL 來源。附件採預簽章直傳，瀏覽器會直接打到儲存端點，不經應用層。
啟用 OIDC 後管理員登不進去 本機密碼登入會在設定 OIDC_ISSUER 後自動停用。以 inkbase admin break-glass 產生 15 分鐘有效的一次性登入連結，修正對應設定後再關閉。
升級後 Webhook 全部停用 v4.2 起簽章演算法改為 HMAC-SHA256，舊訂閱者驗證失敗即連續退避重試，24 小時後依政策自動停用。請先更新接收端，再以 inkbase webhook reactivate --all 復原。
