▶ ABOUT THIS GAME STAGE 08 · 1986 STYLE

◈ NEON RAIDERS · Retrovolt Studio · 臺北

NEON RAIDERS 是臺北獨立工作室 Retrovolt Studio 歷時三年打造的橫向捲軸射擊遊戲。故事設定於 2099 年，玩家扮演四名飛行員組成的突擊小隊，在霓虹都市廢棄軌道網絡中對抗自主兵器 AXIOM-9。全遊戲共八關，每關結束時得分即時同步全球排行榜。本次祭典設有實體大型機台，支援四人同台合作；首次 1CC 過關者可獲限定版紀念徽章一枚。

工作室成立於 2021 年，由三名遊戲開發者與一名音樂製作人組成。本作使用自製像素引擎 PixelCore v2 開發，全遊戲音樂以真實 8-bit 音源晶片錄製，非軟體模擬。

「我們想重現那個插幣進街機、全廳鴉雀無聲的瞬間。這款遊戲就是為了那種感覺而生的。」 — 製作人 林承恩 · Retrovolt Studio

▶ CONTROLS 對照上方控制面板編號

1

八向搖桿

移動飛機，支援類比搖桿與 WASD。斜向輸入判定寬容度 22.5 度。

2

Z · 主砲

長按蓄力，放開發射擴散彈。蓄滿時機身外框會閃爍黃光。

3

X · 僚機砲 / C · 迴避

僚機砲限彈 30 發，撿取補給恢復；迴避為無敵滾轉，冷卻 8 秒。

4

START / SELECT

START 暫停並可召喚離線隊友復活；SELECT 切換武器配置，全場限 3 次。

5

COIN

祭典期間 CREDITS 無限，投幣鍵僅用於中途加入第 2–4 位玩家。
