About.

我們相信，資訊的清晰度就是公共服務本身的一部分。

Civic Dispatch 是臺北市政府公開資料計畫下的城市資訊展示平台。我們彙整交通、環境、公共服務三大面向的即時數據，以 1950 年代瑞士國際主義的排版原則呈現：有限的字體、嚴格的網格、克制的色彩。設計不喧賓奪主，而是讓數字自己說話。

01 — 三項原則

Principles
01

Timeliness即時性

所有數據直接來自各局處開放資料平台，每五分鐘自動同步。我們不接受未經核實的資料，確保每一個數字都可溯源、可驗證，並附有取得時間戳記。逾時未更新的欄位會標記為「停滯」而非沿用舊值。

02

Clarity清晰性

採用瑞士國際主義排版：單一無襯線字體家族、12 欄網格、黑白加一個紅色。所有圖表拒絕裝飾性 3D、漸層與陰影，資料墨水比（data-ink ratio）優先於視覺趣味。

03

Openness開放性

平台內所有資料以 CC BY 4.0 授權公開，API 端點免費使用，開放市民、研究者與媒體不受限地取用。再利用時須保留原始出處標示，不得宣稱為官方公告。

04 — 資料管線

Data Pipeline
Stage 01

原始層

透過政府開放資料平台 API 取得原始 JSON / XML，保留完整回應與 HTTP 標頭，不做任何修改即寫入冷儲存，作為日後爭議時的比對依據。

Stage 02

清洗層

自動剔除超出統計 3σ 範圍的異常值並標記為待審；補齊欄位命名、單位與時區。人工複核佇列每日 09:00 與 17:00 各清空一次。

Stage 03

呈現層

統一格式後推送至前端，圖表數值一律保留原始精度、不做四捨五入美化。原始資料同步開放 CSV / GeoJSON 下載。

07 — 常見問題

FAQ
資料更新頻率是多少？
交通數據（捷運、公車、YouBike）每 5 分鐘同步一次；空氣品質指標每 15 分鐘更新；施工公告與場館狀態每 30 分鐘更新。所有數據皆附時間戳記，可追溯最後同步時間。若上游 API 連續三次逾時，該欄位會顯示為「停滯」並保留最後成功取得的時間，不會沿用舊值假裝仍在更新。
我可以下載原始資料嗎？
可以。本平台所有彙整資料均可透過 API 端點取得，格式包含 JSON、CSV 及 GeoJSON。詳細 API 文件請參閱開放資料平台說明頁面。使用前請遵守 CC BY 4.0 授權條款，保留原始出處標示；商業再利用不需另行申請，但不得暗示本平台為其背書。
資料如有誤，如何回報？
請透過本平台底部的「資料錯誤回報」表單提交，或直接寄信至 data@civicdisp.gov.tw。數據品管小組將在 24 小時內確認並更正。影響行車安全的嚴重錯誤（如施工路段資訊有誤）將在 2 小時內緊急更正，並於首頁通報欄位標示更正紀錄。
這個平台是政府官方網站嗎？
Civic Dispatch 是臺北市政府資訊局委託製作的展示平台，資料來源為市府各局處之開放資料 API。平台本身並不代替任何官方公告；如有重要行政事項，請以各主管機關公告之正式文書為準。本平台亦不受理陳情、申辦或檢舉業務。
為什麼版面只用黑白紅三色？
這是瑞士國際主義排版的核心約束：色彩用於建立層級，而非裝飾。紅色在本站只承擔三種語意——強調數值、標示可點擊、警示異常。若增加第四種顏色，紅色的訊號強度就會被稀釋。同理，全站只使用一個字體家族，靠字重、字級與字距建立階層。
