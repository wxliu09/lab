API 快速上手

API QUICKSTART
# 1. 申請 API 金鑰（會員中心 → 開發者專區，即時核發）
# 2. 呼叫範例：查詢空氣品質即時值
curl "https://data.digigov.example.tw/api/v2/aqi?city=taipei" \
  -H "X-API-Key: YOUR_KEY"

# 回應（節錄）
{
  "station": "中正",
  "aqi": 42,
  "status": "良好",
  "published": "2026-08-28T20:00:00+08:00"
}

# 速率限制：每金鑰每小時 1,000 次；超限回傳 HTTP 429

授權與使用規範

LICENSE

✅ 可以

自由重製、改作、編輯與商業利用，無需事先取得書面許可；於產品中標示資料來源與釋出日期即可。

⚠️ 注意

資料依現況提供，本部不保證其即時性與完整性；涉及個資之衍生利用，須另符合個人資料保護法規定。

🚫 禁止

不得以資料從事詐騙、身分冒用或損害第三人權益之行為；違者本部得停止 API 存取權限。
