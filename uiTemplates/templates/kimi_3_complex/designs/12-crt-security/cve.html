CVE-2026-21487CRITICAL 9.8
發布日期 2026-08-26 09:00 (UTC+8)
CVSS 3.1 向量 AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
影響產品 OpenFlow 路由套件 3.2.0 – 3.4.1(3.4.2 已修復)
弱點類型 CWE-787 堆疊緩衝區溢位(Out-of-bounds Write)
利用狀態 已觀測到野外利用(Exploit in the Wild)
漏洞位於 OpenFlow 套件處理 LLDP 封包之解析函式,攻擊者發送特製封包即可觸發堆疊溢位, 不須任何身分驗證即可於目標設備上執行任意程式碼,最高可取得 root 權限。 由於路由設備通常位於網路骨幹,遭控制後可進行流量攔截、竄改與橫向移動,風險極高。
>> 處置步驟 1: 立即升級至 OpenFlow 3.4.2。
>> 處置步驟 2: 檢查對外 8443/TCP 埠是否必要,非必要立即關閉。
>> 處置步驟 3: 複核 8 月 20 日起之設備日誌,搜尋異常 LLDP 封包特徵(IoC 見通報附件)。
>> 處置步驟 4: 無法立即更新者,先以 ACL 限制管理介面來源 IP。
CVE-2026-20931HIGH 8.1
發布日期 2026-08-24 14:30 (UTC+8)
CVSS 3.1 向量 AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N
影響產品 CloudBridge 儲存閘道 5.0 – 5.3.2
弱點類型 CWE-862 缺少授權檢查(Missing Authorization)
利用狀態 概念驗證程式(PoC)已公開
閘道之物件讀取 API 僅驗證使用者登入狀態,未核對物件所屬租戶,已驗證使用者 可修改請求中的物件路徑,越權讀取其他租戶之儲存物件,造成機敏資料外洩風險。
>> 緩解措施 1: 啟用物件層級 ACL 稽核,告警異常跨租戶存取。
>> 緩解措施 2: 暫停公開分享連結功能,等待廠商熱修復(預計 8/31)。
>> 緩解措施 3: 複查近一週存取日誌,確認是否有異常大量下載行為。
CVE-2026-19804MEDIUM 5.9
發布日期 2026-08-21 10:00 (UTC+8)
CVSS 3.1 向量 AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:N/A:N
影響產品 MailGate 郵件伺服器 8.x(所有啟用舊版 TLS 之組態)
弱點類型 CWE-757 協商降級(Downgrade Attack)
利用狀態 尚無公開利用,屬組態面風險
伺服器在 TLS 交握階段接受降級至 TLS 1.0/1.1 之舊式加密套件,位於網路路徑上之 中間人攻擊者可強制連線降級,進而解密傳輸內容。僅需調整組態即可消除風險,無需更新版本。
>> 修正方式 1: 於 mailgate.conf 設定 tls_min_version = 1.2。
>> 修正方式 2: 停用 3DES、RC4 等過時加密套件。
>> 修正方式 3: 以外部掃描工具複驗,確認僅接受 TLS 1.2 以上。

影響產品 PrintSpool Plus 2.1 – 2.2(僅限啟用偵錯模式)
弱點類型 CWE-532 日誌中儲存敏感資訊
利用狀態 僅本機低權限讀取,影響輕微
啟用偵錯模式時,列印佇列之文件名稱與使用者帳號會以明文寫入全域可讀之日誌檔, 本機使用者可讀取他人列印行為資訊。預設組態未啟用偵錯模式,不受影響。
>> 修正方式 1: 確認 debug = off(預設值)。
>> 修正方式 2: 日誌目錄權限設為 750,僅服務帳號可讀。
>> 修正方式 3: 下次例行更新(2.3 版)將內建日誌脫敏。
